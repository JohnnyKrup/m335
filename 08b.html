Das Gerüst der Klasse:

public class QuestionEditActivity extends AppCompatActivity {

    /**
     * Log-Tag für das ganze Modul 335.
     */
    private static final String TAG = "Modul335";

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        EdgeToEdge.enable(this);
        setContentView(R.layout.activity_question_edit);

        // 16dp eigener Rand, in Pixel umgerechnet über die Dichte des Geräts.
        final int extraPadding = Math.round(16 * getResources().getDisplayMetrics().density);

        // Type.ime() ist die Tastatur. Fünf Eingabefelder auf einem
        // Bildschirm, und ohne diese Zeile legt sie sich über das Feld,
        // in das du gerade tippst.
        ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.clQuestionEdit), (v, insets) -> {
            Insets systemBars = insets.getInsets(
                    WindowInsetsCompat.Type.systemBars() | WindowInsetsCompat.Type.ime());
            v.setPadding(
                    systemBars.left + extraPadding,
                    systemBars.top + extraPadding,
                    systemBars.right + extraPadding,
                    systemBars.bottom + extraPadding);
            return insets;
        });

        Log.d(TAG, "QuestionEditActivity onCreate");
    }
}

Und @android:drawable/ ist nicht dein R. Das Plus-Zeichen kommt von Android selbst, wie android.R.layout.simple_spinner_dropdown_item bei deinen Spinnern. Wer das android: davor weglässt, sucht das Bild in seinem eigenen Projekt und findet es nicht.

So prüfst du A3.

  2. Scroll die Liste. Der Knopf bleibt an seinem Platz, er scrollt nicht mit.
  3. Tipp ihn an. Dein Formular geht auf. Titel Neue Frage, darunter die Felder.
  4. Tipp in den Fragetext. Die Tastatur erscheint und verdeckt das Feld nicht. Fehlt das Type.ime(), liegt sie darüber.

Was vorgegeben ist

Die Regel für den Fragetext steht hier vollständig. Die Schleife über die vier Antwortfelder baust du selbst.

/**
 * Prüft alle Felder und zeigt die Fehler dort an, wo sie entstehen.
 *
 * (HIER: warum die Methode weiterprüft, statt beim ersten Fehler
 *  auszusteigen, zwei bis drei Zeilen)
 *
 * @return true, wenn alle Eingaben brauchbar sind
 */
private boolean isFormValid() {
    boolean valid = true;

    if (textOf(etQuestionText).length() < MIN_TEXT_LENGTH) {
        tilQuestionText.setError(getString(R.string.error_question_text));
        valid = false;
    } else {
        tilQuestionText.setError(null);
    }

    ... hier deine Schleife über answerFields ...
    ... ist ein Feld leer, dann die Meldung error_answer_required
        am passenden answerLayouts, und valid auf false ...
    ... ist es gefüllt, dann setError(null) am passenden answerLayouts ...

Zwei Hinweise, mehr brauchst du nicht.
