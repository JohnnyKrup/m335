Feld 3: Mein Ankerplan

Stell dir vor, dein äusserstes Kästchen aus Feld 2 wäre ein ConstraintLayout. Eine Zeile pro Element, das direkt darin liegt. Kein XML, Worte reichen. Beispiel: "unten an parent" oder "oben an tvTitle".

Reihen­folge Element Waagrecht hängt an Senkrecht hängt an Breite Höhe
Die Regel, an der du jede Zeile prüfst. Jedes Element braucht einen waagrechten und einen senkrechten Anker. Bleibt eine Zelle leer, landet dieses Element beim Start in der linken oberen Ecke. Das ist der häufigste Fehler im ganzen Modul.
Mit welchem Element würdest du anfangen und warum?
Wo hast du 0dp gesetzt, und welche zwei Anker hat dieses Element dort?
Selbstcheck Feld 3
  • Keine leere Zelle bei waagrecht oder senkrecht.
  • Jeder Name folgt der Präfixregel aus 01C, also tv, et, iv, btn, ll.
  • Wo 0dp steht, hat das Element auf dieser Achse zwei Anker.
  • Die Reihenfolge beginnt bei einem Element, das an parent hängt.
  • Ich kann meinen Plan einem Lerngspänli in zwei Minuten erklären.
